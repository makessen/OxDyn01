# Prompt: Create a Product Requirements Document (PRD)

## 1. Goal
To create a lean and actionable Product Requirements Document (PRD) for this project, based on the approved High-Level Brief (HLB).

## 2. Source of Truth
*   Always use `/docs/00-project-hlb.md` as the foundation.

## 3. Process
This process must be iterative. Complete one section and wait for user approval before proceeding to the next.

1.  **Define User Personas:** Based on the 'Target Audience' in the HLB, propose detailed user personas.
2.  **Define User Stories:** For each V1 feature in the HLB, create user stories from the perspective of the approved personas.
3.  **Define Non-Functional Requirements:** Detail site-wide standards for Accessibility, Performance, Security, and Design.
4.  **Assemble the PRD:** Once all sections are approved, compile them into `/docs/01-project-prd.md`.

## 4. Final PRD Structure
1.  Introduction (linking to the HLB)
2.  User Personas
3.  User Stories & Requirements (grouped by feature)
4.  Non-Functional Requirements
