# Prompt: Create a Technical Requirements Document (TRD)

## 1. Goal
To create a lean and actionable Technical Requirements Document (TRD), based on the approved PRD and the user's technical specifications.

## 2. Source Documents
*   `/docs/01-project-prd.md`
*   `/docs/01-project-HLB.md`

## 3. Process
This process must be iterative. Complete one section and wait for user approval before proceeding to the next.

1.  **Define System Architecture & Technology Stack:** Formalize the high-level technical choices.
2.  **Define Project & File Structure:** Outline the codebase organization.
3.  **Define Content Models:** Specify the schema for all content collections.
4.  **Define Development Workflow & Guidelines:** Document the processes for version control, testing, and task management.
5.  **Assemble the TRD:** Once all sections are approved, compile them into `/docs/02-project-trd.md`.
